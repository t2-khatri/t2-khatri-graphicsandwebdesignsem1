About

About Me

I am a motivated Digital Media student at UWE Bristol, developing skills in creative coding, visual communication, interactive design and digital creativity. My work investigates how code, layout and interaction can shape expressive yet functional media experiences.

Over the past year I have produced a range of projects, from generative p5.js sketches to responsive web layouts and a small game prototype. Graphic Composition

Graphic Composition Project

This project explores how rhythm, contrast and flow can be expressed using simple geometric shapes, tone variation and controlled layout. Each composition was created in Figma using a structured grid, demonstrating how design principles can guide visual hierarchy and user attention.

Designed in Figma using consistent spacing, tonal variation and a 12-column grid.

Composition 1 - Rhythm: Repeated Circles

A modular grid of circles with varied tone and alternating emphasis. The repeated arrangement creates a rhythmic visual pattern, showing how consistency and controlled variation can generate movement and balance within a layout.

Composition 2 - Contrast: Light vs Dark

Strong tonal contrast is created by placing a large dark block beside a bright square, with a grid of smaller dark elements on the right. The shift in scale and tone directs attention and demonstrates how contrast controls hierarchy in visual design.

Composition 3 - Flow: Curved Paths

Overlapping curved lines create a smooth directional flow from left to right, with strategically placed circular accents guiding the eye. The layered strokes demonstrate movement, continuity and visual harmony through controlled curvature.

Creative Coding

Creative Coding Projects

In creative coding I use p5.js to explore randomness, contrast and repetition as design strategies. These sketches demonstrate how simple rules and loops can generate complex patterns while still remaining clear enough to be recreated on paper.

Randomness Project

A generative sketch that uses randomised positions, shapes and grey tones to build different compositions on each refresh. It investigates how computational randomness can be used to produce visual variety and organic-looking structures.

View Randomness Sketch

Contrast Project

This p5.js piece focuses on visual contrast by placing heavy black forms against lighter shapes. Adjusting size, tone and spacing showed me how contrast can guide attention and create clear focal areas.

View Contrast Sketch

Repetition Project

The repetition project uses loops and a simple motif to design a patterned grid. It demonstrates how repeated elements create unity and rhythm and how systematic thinking in code can support consistent visual outcomes.

Reflection

Project Reflection

Bringing these projects together in a single portfolio has helped me see the connections between creative coding, graphic composition and web design. Revisiting my randomness, contrast and repetition sketches showed how my understanding of composition and rule-based design has developed across the year.

Designing the layout in Figma and then implementing it with HTML, CSS and the Bootstrap grid made the role of alignment, spacing and responsive behaviour much clearer. Testing the site on different devices highlighted how small adjustments to typography or breakpoints can improve readability and focus.

Overall, the portfolio has increased my confidence in moving between design tools and code. It has confirmed my interest in working at the intersection of creativity, technology and interactive media, and it provides a starting point for future projects that explore more advanced forms of digital storytelling and experimentation.
